CityPress 是一个《都市：天际线 II》模组。它观察城市中实际发生的变化和模拟统计，按编辑规则筛选值得报道的素材，交由玩家配置的 Chat Completions 兼容服务写作，再组织成可在游戏内阅读、可归档并导出为 Word 的主题报纸。

原版游戏通过统计面板和事件提示展示城市信息，但没有报纸、选题、往期档案或可导出的刊物。CityPress 补上这层编辑与出版能力，不改变城市管理的核心规则。

**当前版本：** `1.0.1`，首个正式版的维护更新。已发布构建见[下载页](https://github.com/Daotie/CS2-CityPress/releases)，已有存档数据和历史报纸可继续读取。实际验证范围见[版本说明](RELEASE_NOTES.md)。

## 功能

### 城市观测

- 记录原版游戏中的工具提交与管理回调，覆盖道路、建筑、分区、地形、政策、预算、税收、贷款、购地和公共交通线路设置。
- 校对建筑、路网区段、区域、公共交通线路和树木的实际变化，包括进入施工、施工结束、废弃、损毁、火情和移除。
- 采样人口、经济、就业、教育、健康、旅游、客货运等城市统计，以及市库、贷款、用地、水电、天气和污染等可用数据。
- 合并重复操作，过滤自动改名、逐乘客上下客、界面导航和空预览等已知噪声。
- 区分“操作意图”和“实际结果”：工具提交不等于建成数量，路网区段也不等于整条道路。

### 编辑流程

- 先在本地按主题归并建设与管理变化，整理金额、人口和单位，过滤常规运营清单、低影响事故、资产规格和无法解释的内部字段。本地记录的范围与送入模型的素材范围不同。
- 检测人口、市库、月度预算收支等已确认的数值突破；交通报道区分施工、线路设置和实际投入运营。
- 重大事件有足够素材时，主提示词直接要求完整长评，通常700至1400字、含2至4个小标题；多个独立议题可附不同角度短评或追加评论版。
- 审校接收完整编号稿件和事实要求，可补写、扩写、改写、合并和删除，修订后再次核实数字、来源、措辞与重复内容。
- 缺稿触发补稿：模型仍漏报已确认的新线运营或数值突破时，本地事实工具补成简讯。长评有限重试后仍未完成时先发行合格新闻，保留缺项记录，不为凑篇幅编造评论；不完整成稿不会锁入完整缓存。
- 模型正文格式错误或截断时可用已确认事实恢复。严重事实错误稿件会被清理，缺少评论、版面或稿件不再单独作为拒刊理由。接口鉴权、网络等外部故障仍需按错误信息处理。
- 同主题素材可连续加版；要闻导读概括重要专题并标注最终版号，薄小消息只留在专题版。

### 报纸、档案与导出

- 按素材生成要闻、经济与财政、城市建设与交通、民生与社会、环境与观察以及独立评论版等主题版面。
- 游戏内支持版面目录和上一版/下一版切换；提供通栏头条、侧栏主稿、纵向头条、综合短讯、长评论专版和长评论加短评六种布局。
- 版式计划随报纸保存，游戏预览与 Word 导出使用同一套栏宽和内容块；重新打开、命中缓存和重新导出不会重新排版。
- 先保存本地 JSON 归档，再导出 Word；Word 使用共享内容与版式计划，文字可编辑。原文件无法覆盖时自动另存副本，目录不可用时改存本地归档；全部保存失败时仍可在界面阅读成稿并重新导出。
- 支持自定义报纸名称、自定义导出目录、单存档或全局设置，并可在游戏内打开实际导出文件夹。
- 界面与状态/错误消息跟随游戏语言，内置英文与简体中文并提供回退，其他游戏语言使用英文。报纸正文语言由编辑方针决定，Word 版签跟随报纸内容检测到的语言。
- **默认手动生成**。可选开启每日自动发行，在跨日后编印前一天的报纸并在游戏内打开。
- 已完成报纸复用本地缓存，按服务实际返回值显示缓存或 token 用量；指标没有变化的重复快照不会触发生成。

## 工作原理

1. **观测。** 游戏系统记录操作、城市变化、事件档案和统计采样。载入已有城市时先建立基线，不把现有城市误报成新建。
2. **记录。** 按游戏日聚合记录，同时保存在游戏存档和本地日志文件中。
3. **评估。** 编辑简报评定事件与事实等级，过滤噪声，并判断重大事件是否值得配发独立评论。
4. **写作。** 将符合条件的素材和玩家的编辑方针发送到配置的 Chat Completions 兼容接口；服务返回包含版面和文章的结构化 JSON。
5. **检查与补稿。** 核对数字、来源和措辞，由审校增删改补，再补入仍遗漏的已确认事实；合格新闻照常发行。
6. **规划与排版。** 确定性规划器决定版面主题、文章分布、是否加版以及评论版布局，不会生成空白版面凑数。
7. **保存与导出。** 报纸写入内部归档，导出为 Word 和 JSON，之后可重新打开阅读。

语言模型负责撰写正文；版面结构、事实校验和发布规则由模组决定。生成的报道基于实际采集到的观测，不构成经过独立核实的新闻报道。

## 与原版游戏机制的区别

- **从临时面板到可保存的刊物。** CityPress 保存逐日记录和已出版报纸，支持往期档案与 Word 导出。
- **从数据罗列到编辑取舍。** 重复操作会合并，噪声会被过滤，只把有新闻角度的素材送去写作。
- **明确区分意图与结果。** 工具提交、施工标记、建成设施和实际线路运营被记录为不同事实，避免混为一谈。
- **写作服务可配置。** 玩家可以选择接口、模型和输出参数，项目不绑定单一服务商。
- **不修改模拟规则。** CityPress 只增加观测、编辑和导出能力，不新增建筑、政策或经济机制。

## 安装

在 [Paradox Mods](https://mods.paradoxplaza.com/mods/166126/Windows) 订阅 CityPress，加入启用的游玩集并重启游戏。也可从 GitHub 下载完整安装包手动安装。

1. 从 [Releases](https://github.com/Daotie/CS2-CityPress/releases) 下载完整的 `CityPress-<版本>.zip`。不要把 GitHub 自动生成的源码包当作安装包。
2. 关闭游戏。
3. 将整份压缩包解压到 `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\CityPress`，保持 DLL、界面文件、`Templates/` 和 `images/` 的相对位置。
4. 重新启动游戏，并在本地模组配置中启用 CityPress（若未自动启用）。

安装包包含编译好的 DLL、Harmony 依赖、界面资源与 Word 模板，不包含游戏程序集。升级时请在游戏关闭状态下替换模组目录；原有日志、设置、密钥和导出内容会保留。

启动后可在 `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Logs\CityPress.log` 确认实际加载的版本。

## 使用

1. 在游戏界面点击报纸按钮打开面板。
2. 在编辑部设置中填写 API 地址、模型和密钥，或保留 DeepSeek 默认值；本地兼容服务可以使用 HTTP 并关闭鉴权。
3. 保存设置后点击“生成本日新闻”，为当前游戏日生成报纸。除非开启自动发行，否则不会自动生成。
4. 使用版面上方目录或上一版/下一版按钮阅读不同版面。
5. 在往期档案中阅读已出版报纸，或补编有记录的历史日期。
6. 使用“导出当前报纸”重新导出当前报纸（不调用 API），使用“打开导出文件夹”打开实际目录。

界面与系统消息跟随游戏语言，内置英文与简体中文，其他语言回退为英文。内置编辑方针随中英文界面语言切换，玩家自定义方针保持不变；Word 版签跟随报纸内容检测到的语言。版面切换、档案列表和设置项的具体说明见[完整使用指南](docs/USER_GUIDE.zh-CN.md)。

## 配置

设置可应用为全局默认或单存档覆盖。主要选项如下：

| 设置项 | 作用 | 默认值 |
| --- | --- | --- |
| 每日自动发行 | 跨日后编印前一天报纸并在游戏内打开 | 关闭 |
| 报纸名称 | 自定义报头；留空时跟随城市名 | 城市名 + 日报 |
| 导出目录 | Word/JSON 的绝对导出目录；留空使用“文档/CityPress” | 文档/CityPress |
| API 地址 | 兼容服务的基础地址或完整 `chat/completions` 地址 | `https://api.deepseek.com/chat/completions` |
| 模型 | 服务提供的模型名称 | `deepseek-chat` |
| API 密钥 | 对应地址的 Bearer 密钥；本地服务可关闭鉴权 | 空 |
| JSON 模式 | 发送 `response_format: {"type":"json_object"}` | 开启 |
| 最大输出 tokens | 单次请求的输出上限 | 8192 |
| 最长等待秒数 | 单次请求的最长等待时间 | 180 秒 |
| 输出上限参数 | `max_tokens` 或 `max_completion_tokens` | `max_tokens` |
| 版式选择 | 按内容选版，或从合适模板中适度随机 | 自动 |
| 独立长评论 | 重大事件直接要求长评，必要时另行补写 | 开启 |
| 质量检查 / 自动修订 | 检查成稿并交给模型增删改补；补写可能增加 API 调用 | 开启 |
| 编辑方针 | 追加给编辑的写作说明 | 内置方针 |

兼容接口需要接受与 OpenAI Chat Completions 类似的请求结构和 JSON 响应。基础地址会被规范化为 `/chat/completions` 路径；本地服务可以关闭鉴权。若服务不支持 `response_format`，可以关闭 JSON 模式，但模型仍需返回约定的 JSON 结构。

API 密钥按归一化后的请求地址分别保存，使用 Windows DPAPI 加密，不写入城市存档。请求不会自动跟随重定向。生成时只发送编辑所需的数据：城市/报纸名称、游戏日期、有效操作摘要、筛选后的城市统计和编辑方针。服务商的计费与数据处理规则适用。

## 兼容性

- **平台：** Windows。
- **游戏版本：** 支持 `1.6.*`。 当前构建使用《都市：天际线 II》`1.6.3f1` 的游戏程序集编译，本地检查也基于该版本；其他游戏版本尚未验证。
- **运行方式：** 以 `net48` 游戏模组运行，随包附带 Harmony 2.2.2；界面构建为游戏 UI 模块，React、React DOM 与 UI 运行时由游戏提供。
- **接口协议：** Chat Completions 兼容的 HTTP 服务。这里指的是协议兼容，不表示原生支持所有服务商的专有 API。
- **存档数据：** 存档外层保持版本 1，新字段为追加式；已有安装和旧报纸可继续读取。
- **第三方模组：** 独立模组的行为、快照之间的短暂状态和无法读取的内部数据可能缺失。兼容面板会显示已接入的管理回调与采集异常。
- **渲染差异：** 游戏内 Cohtml 与 Word 的字形度量和物理分页可能不同；Word 为可编辑文字，不保证与游戏内视图逐像素一致。

## 性能

CityPress 在设计上避免在模拟关键路径上集中执行重任务：

- 采集按帧切分为有数量和时间上限的批次，不在单个 tick 内扫描整座城市。
- 快照校对与统计采样按计划间隔执行，并等待上一轮完成后再开始下一轮，遵循游戏自身的更新节奏。
- 日志写入、档案读取、Word 导出和报纸生成在后台线程执行；界面状态与游戏时钟分开更新。
- 已完成报纸使用本地缓存，指标没有变化的重复快照不会再次请求生成。

项目不承诺固定帧率或性能指标。实际开销取决于城市规模、实体数量、其他模组、磁盘速度以及配置的 API 服务。单次请求最长可达配置的等待时间；生成过程是异步的，但网络延迟仍会影响报纸出现的时间。

## 常见问题

**没有生成报纸。** 默认是手动生成。请确认城市时间已经就绪、当天有可刊发素材，并且没有正在进行的生成任务。没有有效素材的日期会生成简短空刊，不发送 API 请求。

**API 请求失败。** HTTP 401 通常表示密钥缺失、无效或与服务地址不匹配；请核对地址、密钥与鉴权开关。其他错误需检查模型、输出参数和超时设置。不兼容 `response_format` 时可关闭 JSON 模式。截断的模型稿会尝试用事实简讯恢复，不作为完整成稿缓存。

**Word 无法覆盖或目录不可用。** 无需重新请求 API，点击“导出当前报纸”重试。模组会尝试另存新副本或保存到本地归档，界面提示实际结果；导出失败不会再隐藏成稿。

**评论版没有出现。** 需要重大事件、足够素材及长评论选项。主请求直接要求长评，审校可补写，必要时再进行有限的独立评论重试。仍未完成时先发行合格新闻，保留缺项记录，并允许后续重新生成补齐。

**旧报纸还是原来的版面。** 已归档报纸保留其保存时的版式。需要重新生成该日期才会使用当前版式和编辑规则；重新导出旧报不会改写内容。

**报纸里的数字和游戏面板看起来不同。** 月度预算收入、预算结余和市库余额是不同口径，会分别标注。报纸使用该游戏日采集到的事实，不是实时面板，也不能补回未观测到的历史。

**文件保存在哪里？** 设置、日志、缓存和内部报纸 JSON 位于 `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\ModsData\CityPress`。Word/JSON 默认导出到 `文档/CityPress/<报纸名称>/存档-<存档标识>/`。

**可以使用本地模型吗？** 可以，只要服务提供 Chat Completions 兼容接口；本地服务不需要鉴权时可关闭鉴权。项目本身不内置或运行模型。

## 开发构建

完整构建需要 Windows、.NET SDK 10、Node.js 20+，以及提供游戏程序集的本地《都市：天际线 II》安装。游戏程序集和生成的发行包不纳入版本控制。

```powershell
./build.ps1 -ManagedPath '<Steam 游戏库>/steamapps/common/Cities Skylines II/Cities2_Data/Managed'
```

也可设置环境变量 `CSII_MANAGED_PATH`。脚本会编译模组、运行测试、使用游戏程序集执行回调检查、构建并类型检查界面、审计运行依赖，并按 `VERSION` 打包。

不依赖游戏文件的检查：

```powershell
dotnet run --project Tests/CityPress.Tests.csproj -c Release -- --core-only
npm ci --prefix UI
npm run typecheck --prefix UI
npm run build --prefix UI
npm audit --prefix UI --omit=dev
```
