**0.2.0-beta.8:** Commentary-edition release — a long analysis with its own subheadings, short comments on the same opinion page, and page planning that adds editions when the material needs the space. It builds on the beta.7 editorial pipeline: independent commentary generated by its own task, deterministic themed editions and a pre-layout quality gate. See [release notes](RELEASE_NOTES.md) and [changelog](CHANGELOG.md). The interface, default editorial policy and Word furniture currently use Simplified Chinese; public documentation is bilingual.

## What it does

- Records meaningful tool and management submissions, observed city changes and important event updates.
- Samples available city statistics, finances, transport, utilities, weather and pollution; combines repeated records.
- Excludes automatic vehicle renaming, individual boarding/alighting, UI navigation and empty previews.
- Sends eligible summaries to your configured Chat Completions-compatible service when requested; DeepSeek remains the initial default. The editor chooses worthwhile stories, merges repetitions and can leave an issue without articles.
- Organizes worthwhile material into themed editions (such as news, economy, transport, public services and commentary), with page navigation in game and matching themed page breaks in editable Word. Older single-page issues remain readable.
- Grades news value (routine, notable, major, milestone, critical) and uses a deterministic page planner: a flat model response or a single "综合" edition is split into themed editions, and a single-domain day stays one page instead of being padded.
- Generates an independent commentary as a separate editing task for major events with enough material, validates it, retries once with the concrete problem, and never publishes a news-only issue if it fails. A bare threshold without supporting facts does not force a commentary.
- The commentary edition can carry one long analysis occupying the page (with 2–4 subheadings rendered in game and Word) plus up to two short comments in a sidebar. Long and short pieces are checked by separate standards, and a page of only short notes cannot pass as analysis.
- Pages are not limited to one topic: a rich topic continues onto（续）editions instead of being crammed, page count follows an editorial capacity, and thin pages are merged only when the limit is exceeded.
- Runs a quality gate before layout: numbers must trace to observations, invented sources and interviews are rejected, repeated openings/mechanical phrasing/duplicate stories are flagged or merged, and commentary that reprints news is refused. Unsafe copy is removed rather than published; at most one targeted revision is attempted.
- Records named passenger-line service separately from construction and settings. New service requires enabled routes, distinct stops and actual service vehicles; existing routes establish a baseline.
- Distinguishes reporting, brief news, analysis and opinion, with an editorial gate against technical/process disclaimers in published copy.
- Offers banner headlines, lead/sidebar layouts, vertical headlines, brief-news columns, long-commentary and long-commentary-plus-short-comments layouts. Choose automatic content matching or suitable-template variation; the composition is saved and shared by UI and Word.
- Uses the city name for the masthead or a custom title, saved per city or as a global default.
- Keeps generation **manual by default**. Optional automatic publication generates the previous game day's issue and opens it in game.
- Caches completed issues locally, isolates providers and reports cache/token usage when the chosen service returns it. Resampling unchanged metrics does not regenerate the same facts.

## Install and use

1. Download the complete `CityPress-<version>.zip` from [Releases](https://github.com/Daotie/CS2-CityPress/releases), not GitHub's source ZIP.
2. Exit the game, extract the full package into `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\CityPress`, and restart using your local-mod setup. Keep `Templates/`, `images/` and UI files beside the DLLs.
3. Open the newspaper button, then **编辑部设置** (editorial settings). Set the API address, model and key, or keep the DeepSeek defaults; compatible local services can disable key authentication. Save. Click **生成本日新闻** to generate; daily automatic generation is optional.

Generation sends city facts to the configured service and may incur provider charges. The key is encrypted for the local Windows account, excluded from savegames and not displayed back to the UI. Review [privacy](SECURITY.md) before sharing a journal or newspaper.

Word/JSON exports default to the Windows Documents folder under `CityPress/<newspaper>/存档-<save ID>/`. Choose another absolute folder in editorial settings; **打开导出文件夹** opens the actual location. Re-exporting an existing issue uses no API. Settings, local journals, cache and internal issue JSON remain in `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\ModsData\CityPress`. Read the [detailed player guide](docs/USER_GUIDE.zh-CN.md).

## Coverage and beta status

Observed changes are separate from submitted intentions. Tool submissions are not completed-building counts; network edges are not whole roads. Existing city assets are baselined on load. Statistics and reconciliation cycles are spread across frames; the next cycle starts five game minutes after completion, using the game's underlying update cadence. Persistent high-water marks detect population, treasury, monthly budget income/balance, households, visitors and land breakthroughs; initial samples establish a baseline. Monthly budget figures are rates, not settled receipts. Export and journal writes run on workers; native query copies and job waits can still cause spikes.

Independent third-party mod actions, transient intermediate states and unavailable internal data can be missed. The compatibility panel reports active management bindings and collection errors. Earlier unobserved history cannot be reconstructed. Generated articles are editable output based on available evidence, not verified reporting.

Automated core/cache/export tests, a callback harness and browser UI checks have been run locally. A complete in-game acceptance pass for the expanded collector has **not** been completed. See the validation scope in each prerelease.

## Build

Windows, .NET SDK 10, Node.js 20+ and a local game installation are required for a full build. Game assemblies are not in this repository.

```powershell
./build.ps1 -ManagedPath '<your Steam library>/steamapps/common/Cities Skylines II/Cities2_Data/Managed'
```

Alternatively set `CSII_MANAGED_PATH`. See [architecture](docs/ARCHITECTURE.md), [contributing](CONTRIBUTING.md) and [releasing](RELEASING.md).

Core/cache/Word checks run without game files or an API key: `dotnet run --project Tests/CityPress.Tests.csproj -- --core-only`. This explicitly skips native game-assembly integration; the public CI runs these core checks and the UI build/audit.
