# Support / 支持

Use [GitHub Issues](https://github.com/Daotie/CS2-CityPress/issues) for reproducible bugs and feature requests. Include CityPress version, game version, reproduction steps and relevant errors with secrets removed. State whether the failure concerns collection, generation, in-game layout or Word export.

Beta releases are prereleases. Their notes distinguish automated checks from in-game validation. Independent third-party mod actions and transient states may be missed; the compatibility panel reports available hooks and collection errors.

通过 GitHub Issues 反馈。请注明模组版本、游戏版本、复现步骤和已脱敏错误，并区分采集、生成、界面或 Word 导出问题。Beta 为预发行版本，游戏内验收情况见各版说明。
